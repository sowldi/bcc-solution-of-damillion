# Сервис бронирования книг

## 1. Общие положения

Документ описывает требования к сервису бронирования книг городской библиотеки.

## 2. Функциональные требования

* Ф-1. Читатель бронирует книгу через электронный каталог.
* Ф-2. Система должна быстро показывать результаты поиска.
* Ф-3. Каталог должен отвечать быстро: не более 2 секунд на запрос.
* Ф-4. Библиотекарь подтверждает бронь в течение 4 часов.
* Ф-5. По возможности система предлагает похожие книги.
* Ф-6. При необходимости читатель продлевает бронь.
* Ф-7. Если требуется подтверждение личности, библиотекарь проверяет читательский билет.
* Ф-8. Система уведомляет читателя несколькими способами.
* Ф-9. Напоминание о возврате отправляется несколькими каналами: SMS и электронной почтой.
* Ф-10. Бронь хранится около 3 дней.
* Ф-11. Кнопка продления расположена около обложки книги.
* Ф-12. Система своевременно снимает просроченные брони.
* Ф-13. Она хранит историю броней читателя.
* Ф-14. Данные читателя хранятся в зашифрованном виде.
* Ф-15. Выдача книги фиксируется в АБИС.
* Ф-16. Личный кабинет (ЛК) показывает активные брони читателя.
* Ф-17. Штраф за просрочку возврата: TBD.
* Ф-18. Тариф продления будет определён на дату заявки.
* Ф-19. Каталог поддерживает поиск по автору, названию, жанру и т.д.
* Ф-20. Библиотекарь принимает книгу, отмечает возврат и далее выдаёт её следующему читателю.
* Ф-21. Сводный отчёт по выдаче строится согласно Ф-40.
* Ф-22. Отмена брони выполняется согласно Ф-1.
* Читатель оставляет отзыв о прочитанной книге.
* Ф-23. Порядок выдачи редких изданий описан в разделе 7.
* Ф-24. Система отправляет напоминание о возврате книги.

## 3. Нефункциональные требования

* Н-1. Сервис должен быть надёжным.
* Н-2. Сервис доступен 99,5 % времени в месяц.
* Н-3. Время отклика каталога минимизируется.

## 4. Параметры

| Параметр | Значение |
| --- | --- |
| Срок хранения брони | 3 дня |
| Срок хранения брони | 5 дней |
| Лимит броней на читателя | 5 книг |
| Штраф за день просрочки | — |

## 5. Критерии приёмки

* Дано: читатель авторизован.
* Когда читатель бронирует доступную книгу.
* Тогда бронь появляется в личном кабинете.
* Дано: читатель без действующего читательского билета.
* Когда он бронирует книгу.
